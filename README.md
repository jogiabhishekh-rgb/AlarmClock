# ⏰ Alarm Clock Web App

A feature-rich, modern digital alarm clock application built with React, TypeScript, and Tailwind CSS. Designed to help you stay organized, manage multiple alarms effortlessly, and keep track of time with a sleek, responsive interface.

---

## ✨ Features

- 🕒 **Real-Time Digital Clock:** Displays live time with clear AM/PM indicators.
- 🔔 **Custom Alarms:** Easily create, toggle, edit, and delete multiple alarms.
- 🎵 **Custom Ringtones & Audio:** Select custom tones or sounds for alarm notifications.
- 💤 **Snooze Functionality:** Quick snooze option to delay alarms by set intervals.
- 💾 **Local Storage Persistence:** Keeps your configured alarms saved across page reloads.
- 📱 **Fully Responsive:** Smooth layout optimized for desktop, tablet, and mobile browsers.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
